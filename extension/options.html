金融雷達 NLM 助手 — 設定

v0.5+ 已改為從 popup 內動態下拉選擇 notebook，本頁只設 VM API 與分析提示詞。本擴充功能與系統 hourly 自動排程獨立，不會影響 LINE「分析」指令。

產生報告後會 POST 到 {base}/api/radar/extension-report。如果你沒有自己的金融雷達 VM，請勾下方「不推送」。
推薦：在 VM 前端「Service Keys」頁面建立一把專給 Extension 用的 key（sk_… 開頭），貼這裡。出事時可單獨撤銷不影響其他 client。也接受舊版單一 API_TOKEN（過渡期）。VM 沒啟用驗證就留空。
勾起來：產生的報告只下載 / 顯示在 popup，不會嘗試 POST 給 VM。沒有架設金融雷達服務的使用者請勾這個。

留空使用內建預設
popup 選「🚫 不推送」chip 時用這個提示詞做分析（純本機看、不推 VM）。預設留空，留空時 NotebookLM 會用其內建預設 prompt（`Create a report based on the provided sources.`）。建議用來實驗你自己的 prompt 模板。

⏰ 定時自動 YouTube 分析

瀏覽器開著時，定期自動把「系統偵測到的新影片」匯入下方 notebook 分析、推回系統（分析結果 → 🧩 Extension YT）。 用的是你目前瀏覽器登入的 NotebookLM session，不需要 notebooklm login、不會過期。每輪會清空該 notebook 的非 [SKILL] sources、匯入新影片、產生報告。

需保持 Chrome 開著（service worker 才會被 alarm 喚醒）。停用時排程會清除。
每隔幾小時跑一次，下限 0.5 小時。建議 3（對齊系統影片偵測累積量）。
建議指定一個專用的 YT notebook（會被反覆清空＋重灌新影片）。清單來自你的 NotebookLM。
